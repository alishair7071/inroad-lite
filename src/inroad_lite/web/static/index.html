inroad-lite

Tell it the jobs you want. It finds companies hiring for them right now, checks every opening is real, and ranks them by how well they fit you, with the reason for each one. A small open-source version of Inroad, using Olostep to search the web and read company websites.

About you

Open source: github.com/alishair7071/inroad-lite. This is not Inroad's private code: Inroad's private code, data and keys are not included.
